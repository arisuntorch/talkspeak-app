# TalkSpeak Android

这个仓库只用来分发 TalkSpeak 的 Android 安装包，不含源代码。

## 下载

**[⬇ 下载最新版 APK](https://github.com/arisuntorch/talkspeak-app/releases/latest/download/talkspeak.apk)**

历史版本见 [Releases](https://github.com/arisuntorch/talkspeak-app/releases)。

## 安装

1. 用手机浏览器打开上面的下载链接。
2. 下载完成后点开 APK，按提示允许「安装未知来源应用」。
3. 升级时直接覆盖安装，设置会保留。

## 使用

App 需要连到电脑上运行的 TalkSpeak 服务（同一局域网）。第一次打开会弹出「连接电脑」，填电脑终端里打印的地址（如 `192.168.1.5:8787`）和访问令牌。
